# 许可证合规

## 事实

| 项目 | 许可证 | 影响 |
|---|---|---|
| `ccch1mneyyy/dsh-Go` | **AGPL-3.0** | 复制、修改、分发（含网络服务）必须开源全部衍生作品 |
| `Anrylin/dsh-go-ios` | AGPL-3.0（fork） | 同上 |
| NcnsDSH | **MIT** | 宽松，但**不能**吞入 AGPL 代码 |

## 本轮做法

1. **只读源码**：通过 GitHub API 读取文件用于理解协议与架构；
2. **不复制代码**：没有把任何 Dart/Swift 源文件拷进 NcnsDSH；
3. **不复制资产**：品牌、图标、截图均未使用；
4. **独立实现**：Runtime 协议、沙箱、队列表述均按 DSH 的**概念**重写。

## 若未来要复用 AGPL 代码

必须同时满足：

1. NcnsDSH 整体改为 AGPL-3.0；
2. 提供完整对应源码；
3. 保留原作者版权声明与变更说明；
4. 若作为网络服务提供，需向用户提供源码获取方式。

在那之前，**不得**把 dsh-Go 的 Swift/Dart 文件直接纳入构建。

## 第三方依赖

NcnsDSH 目前无第三方 Swift 包依赖（只用系统框架）。
若后续引入（如 swift-log、MarkdownUI），需逐项核对许可证并记录于此。
