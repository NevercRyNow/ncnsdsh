# NcnsDSH — FLUID INTELLIGENCE · 40 秒产品片：制作包

这份是**可执行的制作包**，不是成片。原因写在最后一节：这台设备渲不出视频。

## 一、能落地的部分 vs 需要真实素材的部分

| 段落 | 能否用纯图形做 | 需要什么真实素材 |
| --- | --- | --- |
| S1 品牌诞生（0–5s） | 能：黑场 + 银色液态光流 + 字标 | 无 |
| S2 进入界面（5–10s） | **不能** | iPhone 实机录屏（首页：hero、Dock、Core、当前会话、模型状态） |
| S3 智能交互（10–16s） | **不能** | 模型轨道滑动 / 推理切换 / 工具能力展开的录屏 |
| S4 工作台（16–23s） | **不能** | 终端 / 文件 / 浏览器 / 改动 / 上下文 五段录屏 |
| S5 引擎（23–29s） | 部分：终端文字可用排版模拟 | Runtime 页真实状态（本机 / 远程 / Linux 不可用） |
| S6 体验混剪（29–35s） | **不能** | 上面各段的素材再剪 |
| S7 品牌收尾（35–40s） | 能：与 S1 同一套光流 + 字标 | 无 |

**结论**：7 段里只有 S1、S7 和 S5 的文字层能纯图形完成；S2–S4、S6 必须有实机录屏。
按总提示词自己的第 05 节要求（「不得假装拥有尚未实现的功能」「界面必须真实可读」），
这些镜头不能用设计稿顶替。

## 二、实机录屏清单（拍什么、怎么拍）

统一规格：iPhone 15/16 Pro，深色模式，字体大小默认，关闭「减弱动态效果」，
控制中心隐藏，录屏 60fps 再用 24fps 抽帧，避免滚动出现频闪。

1. `home.mov` — 冷启动（含启动动画：朦胧玻璃变清晰）→ 停在首页 3 秒
2. `deck.mov` — 模型控制台：横向滑动、选中形变、推理/工具区滚动
3. `chat.mov` — 发一条消息：流式输出 → 工具调用卡 → 停止生成
4. `workbench.mov` — 从首页点「终端」拉起三档 sheet，逐档停留；切 5 个 pane
5. `runtime.mov` — 本机运行时页：能力与限制、内置引擎（启动/未启动状态）
6. `settings.mov` — 设置分区 + 关于页（版本块/制作人块）

## 五、为什么现在交不出成片（证据）

1. **DrawAI 的渲染管线在这台设备上起不来**：`motion_render start` 与 `motion_preview`
   都在 0.2 秒内失败，错误是 `Cannot read properties of null (reading 'on')`；
   查环境：`node_modules` 里没有 remotion、没有 playwright/puppeteer、没有 Chromium。
2. **ffmpeg 没有 drawtext / subtitles 滤镜**（这套环境的内置构建不含自由字体库），
   所以连纯文字卡都渲不出来。
3. **浏览器截图也超时**：用 WebKit 打开本地 HTML 渲一帧，`screenshot` 10 秒不返回。
4. 因此 40 秒 × 24fps = 960 帧的成片**无法在本机产出**；交假片比不交更糟。

## 六、可行的三条路

1. **CI 渲片**（推荐）：在 GitHub macOS runner 上用 puppeteer 逐帧截 1920×1080、
   ffmpeg 编码 H.264，把 mp4 挂到 release。我可以写这条流水线，但**S2–S6 仍然需要你给录屏**，
   否则只能做 S1/S7 的品牌开合与 S5 的文字层。
2. **你在 Mac 上用 DrawAI 桌面版渲**：工程骨架已经在 `docs/design/.drawai-motion/`（未入库，82MB）。
3. **先做 8 秒品牌片**（S1 + S7 合并）：不需要任何实机素材，能完整交付，且气质可先定下来。
